# What is AI? (research notes)

- Definition: AI is a broad field of technologies that let computers mimic cognitive functions linked to human intelligence: seeing, understanding and responding to language, analysing data, making recommendations. (Google Cloud)
- AI is the umbrella term; machine learning is a subset; deep learning is a subset of ML using multi-layer neural networks. (IBM, Google Cloud)
- Machine learning: instead of explicit programming, algorithms analyse large amounts of data, learn from it, and make decisions; performance improves with more data. (Google Cloud)
- ML learns patterns in training data, then makes inferences/predictions about new data; using a trained model is "inference". (IBM)
- Deep learning typically needs very large datasets, often millions of data points. (Google Cloud)
- Before ML, programs had to be programmed for a limited set of inputs (Deep Blue example); improving them meant programmers adding rules by hand. (Coursera)
- Everyday examples: recommendations in streaming and shopping, spam filtering, voice assistants, photo tagging, translation. (Google Cloud table; MIT Professional Education)
